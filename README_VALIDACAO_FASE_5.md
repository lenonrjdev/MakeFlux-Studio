# Validação da Fase 5 — Laboratório de IA

Execute na raiz do repositório:

```powershell
.\VALIDAR_FASE_ATUAL.cmd
```

O homologador valida a estrutura do Laboratório de IA, persistência, operações do workspace, comparação de resultados, presets, transferência para o estúdio, lint, TypeScript, testes, build Next.js, rotas exportadas, Rust, Tauri e instalador desktop.

A fase só deve ser consolidada quando o terminal exibir `FASE APROVADA`.
