# Hotfix de processo — validação automatizada da Fase 3

Esta atualização adiciona uma esteira local de homologação para o repositório inteiro do MakeFlux Studio.

Extraia os arquivos na raiz:

```text
C:\projetos\makeFluxStudio
```

Depois execute:

```powershell
.\VALIDAR_FASE_ATUAL.cmd
```

A fase só está consolidada quando o terminal mostra `FASE APROVADA`.

Documentação completa: `docs/VALIDACAO_DE_FASES.md`.
